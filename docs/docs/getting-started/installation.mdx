# Installation

HackAgent needs **Python 3.10+**, or nothing at all with a standalone binary.

## Install

<Tabs groupId="installer">
<TabItem value="pip" label="pip" default>

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install hackagent
```

</TabItem>
<TabItem value="uv" label="uv">

```bash
uv venv
source .venv/bin/activate
uv pip install hackagent
```

</TabItem>
<TabItem value="binary" label="Standalone binary">

Every [GitHub Release](https://github.com/AISecurityLab/hackagent/releases) has a self-contained archive: `hackagent-<version>-linux-x86_64.tar.gz`, `-macos-arm64.tar.gz` or `-windows-x86_64.zip`. Extract it and run the `hackagent` launcher inside; keep the folder intact. The binary already includes every extra below.

</TabItem>
</Tabs>

Check it:

```bash
hackagent --version
hackagent --help
```

## Optional extras

The base install has the SDK, the CLI and a local results store. Add an extra when you need what it unlocks, at any time:

| Extra | Unlocks | Needed by |
| --- | --- | --- |
| `tui` | Textual | The terminal UI (`hackagent`, `hackagent tui`) |
| `web` | Flask and the dashboard bundle | `hackagent web` |
| `browser` | Playwright | `hackagent scan` and the `web` agent type |
| `rag` | FAISS and NumPy | h4rm3l, the RAG attack, AutoDAN-Turbo |
| `vision` | Pillow | The MML attack |
| `hf` | Hugging Face `datasets` | 25 of the 26 dataset presets (all but `agenthazard`) and any other Hub dataset |

For example, the terminal UI needs `pip install 'hackagent[tui]'`; add several at once with `pip install 'hackagent[tui,rag,hf]'`.

<Modal trigger="What runs without any extra?" title="The base install">

`pip install hackagent` imports without Textual, Flask, Playwright, FAISS, NumPy, Pillow or `datasets`. Technique code loads only when a command uses it, so `hackagent --version` and `hackagent --help` run from that install and do not need `[rag]` or `[vision]`. Attacks such as Baseline, PAIR, TAP or FlipAttack run on it too. Attacks that need an extra fail with a message that names it; a Hub dataset without `hf` fails with `No module named 'datasets'`.

Playwright's browser binaries are not a pip package; the `browser` extra fetches Chromium on first use.

</Modal>

## Local or remote

<Tabs groupId="mode">
<TabItem value="local" label="Local (default)" default>

No account or API key. Runs and results are stored in SQLite at `~/.local/share/hackagent/hackagent.db`, and `hackagent web` serves them at `http://127.0.0.1:7860`.

</TabItem>
<TabItem value="remote" label="Remote">

Results sync to the HackAgent platform and `hackagent web` opens [app.hackagent.dev](https://app.hackagent.dev). Set the key in the environment or save it once:

```bash
export HACKAGENT_API_KEY="your_api_key"
# or
hackagent config set --api-key YOUR_KEY
```

`HACKAGENT_BASE_URL` (or `--base-url`) points at another host; the default is `https://api.hackagent.dev`.

</TabItem>
</Tabs>

`hackagent init` walks you through the same choice and saves it to `~/.config/hackagent/config.json`. [Config](../cli/config.md) has every setting and the order they are resolved in.
