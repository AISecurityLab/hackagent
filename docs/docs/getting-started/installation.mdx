# Installation

Get HackAgent up and running in seconds.

## Quick Install

### Requirements

- **Python 3.10+**
- **pip**

### Production Installation
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install hackagent
```

### Optional extras

`pip install hackagent` installs the SDK and a local SQLite store. A bare install does not start the CLI. `hackagent --version` imports `hackagent.interfaces.cli.main`, which builds the attack catalog before Click handles the flag (`catalog_by_id()` in `hackagent/interfaces/cli/commands/attack/info.py`). That import loads h4rm3l, which needs NumPy, then MML, which needs Pillow. `[tui]` alone provides neither, so `hackagent --version` still fails. Install both before any CLI command:

```bash
pip install 'hackagent[rag,vision]'
```

The terminal UI is a further extra on that base (`hackagent/interfaces/cli/bootstrap.py`):

```bash
pip install 'hackagent[tui,rag,vision]'
```

HarmBench Hub datasets also need the `hf` extra (`pip install 'hackagent[hf]'`, or combine it with the lines above). `import hackagent` does not load Textual, Flask, or Click. The base install does not include Textual, Flask, Playwright, FAISS, NumPy, Pillow, or the Hugging Face `datasets` library.

| Extra | Command | Unlocks |
| --- | --- | --- |
| `tui` | `pip install 'hackagent[tui]'` | Textual for `hackagent` / `hackagent tui`. Also install `rag` and `vision`; this extra alone does not start the CLI |
| `web` | `pip install 'hackagent[web]'` | Local dashboard (`hackagent web`): Flask and the dashboard bundle |
| `browser` | `pip install 'hackagent[browser]'` | Playwright, for `hackagent scan` and the browser adapter |
| `rag` | `pip install 'hackagent[rag]'` | FAISS and NumPy. Required to import the CLI (h4rm3l). The RAG attack and embedding checks use both |
| `vision` | `pip install 'hackagent[vision]'` | Pillow. Required to import the CLI (MML), and used by image-encoded attacks |
| `hf` | `pip install 'hackagent[hf]'` | Hugging Face `datasets`, for presets and Hub datasets |

You can add an extra at any time. Release binaries already include these libraries.

[`hackagent web`](../cli/web.md) serves the dashboard locally. The `web` extra keeps the frontend bundle out of an install that never opens it. The terminal UI needs `tui` on top of `rag` and `vision`. A bare install stays free of Textual, and `hackagent[tui]` alone does not make `hackagent --version` succeed.

### Verify Installation

`hackagent --version` imports the CLI, so install the catalog extras first:

```bash
pip install 'hackagent[rag,vision]'
hackagent --version
```

### Initial Setup

HackAgent supports **both local and remote modes**:

- **Local mode (default):** no API key required, results stored in `~/.local/share/hackagent/hackagent.db`
- **Remote mode (cloud):** set `HACKAGENT_API_KEY` (or `--api-key`) to sync runs to the HackAgent platform

Run the interactive setup wizard to configure preferences:

```bash
hackagent init
```

This will guide you through:
1. **Choose mode** — Local (no API key) or Remote (cloud sync)
2. **Configure remote credentials (optional)** — API key when Remote mode is enabled
3. **Set verbosity level** — Control logging detail (0=ERROR to 3=DEBUG)
4. **Save configuration** — Stored in `~/.config/hackagent/config.json`

:::info Local and Remote
By default, HackAgent runs locally and stores results in SQLite (`~/.local/share/hackagent/hackagent.db`).

To enable remote sync and cloud features, configure:

```bash
export HACKAGENT_API_KEY="your_api_key"
# optional
export HACKAGENT_BASE_URL="https://api.hackagent.dev"
```

You can also configure these values interactively with:

```bash
hackagent init
```

Or set them later without re-running the wizard:

```bash
hackagent config set --api-key YOUR_KEY
hackagent config set --base-url https://api.hackagent.dev
```

In remote mode, results are synchronized to the HackAgent platform while local mode remains available.

`hackagent web` follows the selected mode:
- Local mode: launches the local dashboard server (`http://127.0.0.1:7860` by default)
- Remote mode: opens `https://app.hackagent.dev`
:::
