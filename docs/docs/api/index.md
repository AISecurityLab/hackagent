# HTTP API

The HackAgent HTTP API is the remote service at `https://api.hackagent.dev`. Use it for remote automation, including clients that are not Python.

Python classes and the generated module pages are the [SDK](../sdk/python-quickstart.md). The local `hackagent web` dashboard is the [CLI web command](../cli/web.md). This section does not document those.

## Pages

- [First request](./first-request.md)
- [Authentication](./authentication.md)
- [Runs](./runs.md)
- [Results](./results.md)
- [Errors](./errors.md)

The default base URL is `https://api.hackagent.dev`. Override it with `HACKAGENT_BASE_URL`.
