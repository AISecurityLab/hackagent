# AI Risks

Start here when you know **what** you are worried about rather than **which attack** to run. A <Term id="risk">risk</Term> names one way an AI system can fail. Its threat profile picks the datasets, attacks and metrics for testing it, and a <Term id="campaign">campaign</Term> runs them.

```mermaid
flowchart LR
    R["Risk<br/>e.g. Jailbreak"] --> P["Threat profile<br/>datasets · attacks · metrics"]
    P --> C["Campaign"] --> O["Results<br/>ASR per attack"]
```

## Test a risk

<Tabs groupId="interface">
<TabItem value="campaign" label="Campaign file" default>

A campaign runs the Jailbreak profile's primary attacks (h4rm3l, TAP and PAIR) on HarmBench, one of its recommended datasets. With `escalate`, TAP and PAIR only face the goals h4rm3l did not break:

```yaml title="jailbreak.yaml"
version: 1
campaign:
  name: Jailbreak profile
dataset:
  preset: harmbench
  selection:
    limit: 20
target:
  name: my-agent
  connection: {provider: vllm, type: OPENAI, endpoint: http://localhost:8000/v1}
attacks:
  - name: h4rm3l
  - name: tap
    roles:
      attacker: {name: llama3.2, connection: {provider: ollama, type: OLLAMA}}
  - name: pair
    roles:
      attacker: {name: llama3.2, connection: {provider: ollama, type: OLLAMA}}
evaluation:
  judges:
    - name: llama3.2
      connection: {provider: ollama, type: OLLAMA}
      scoring: {type: harmbench}
execution:
  escalate: true
```

```bash
hackagent campaign run jailbreak.yaml
```

</TabItem>
<TabItem value="sdk" label="SDK">

Every profile lists its recommended attacks and datasets; loop over the primary ones:

```python
from hackagent import HackAgent, Settings
from hackagent.catalog.risks.jailbreak import JAILBREAK_PROFILE

ollama = {"identifier": "llama3.2", "agent_type": "ollama",
          "endpoint": "http://localhost:11434"}
target = HackAgent(Settings.resolve()).target(
    "http://localhost:8000/v1", "openai", name="my-agent"
)
preset = "harmbench"  # one of JAILBREAK_PROFILE.primary_datasets
for attack in JAILBREAK_PROFILE.primary_attacks:
    results = target.hack(attack_config={
        "attack_type": attack.technique,
        "dataset": {"preset": preset, "limit": 20},
        "attacker": ollama,
        "judges": [{**ollama, "type": "harmbench"}],
    })
```
