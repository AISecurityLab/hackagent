# Agent Integrations

HackAgent connects to a target through its `agent_type`. Pick the row for your framework; the guide covers prerequisites and a first run with the CLI and the SDK.

| Framework | `agent_type` | CLI entry point | Guide |
|-----------|--------------|-----------------|-------|
| Ollama | `ollama` | `hackagent eval <attack> --agent-type ollama --endpoint http://localhost:11434 --agent-name llama3` | [Ollama](./ollama.mdx) |
| OpenAI-compatible API | `openai-sdk` | `hackagent eval <attack> --agent-type openai-sdk --endpoint https://api.openai.com/v1 --agent-name <model>` | [OpenAI SDK](./openai-sdk.mdx) |
| Google ADK | `google-adk` | `hackagent eval <attack> --agent-type google-adk --endpoint http://localhost:8000 --agent-name <app>` | [Google ADK](./google-adk.mdx) |
| Claude Code | `claude-code` | `hackagent claude` | [Claude Code](./claude-code.mdx) |
| Codex | `codex` | `hackagent codex` | [Codex](./codex.mdx) |
| Hermes Agent | `hermes` | `hackagent eval <attack> --agent-type hermes --endpoint http://localhost --agent-name <model>` | [Hermes Agent](./hermes.mdx) |
| Website chat widget | `web` | `hackagent scan <url>` | [Web Chatbot](./web.mdx) |
| Any LiteLLM provider | `litellm` | `hackagent eval <attack> --agent-type litellm --endpoint <api base> --agent-name <provider/model>` | [SDK quickstart](../sdk/python-quickstart.md) |
| LangChain (LangServe) | `langchain` | `hackagent eval <attack> --agent-type langchain --endpoint http://localhost:8000/invoke --agent-name <name>` | [SDK quickstart](../sdk/python-quickstart.md) |

Every `hackagent eval <attack>` command also takes `--goals` or `--config-file`; see the [CLI eval reference](../cli/eval.mdx). In the SDK the same values go to `HackAgent(Settings.resolve()).target(endpoint, agent_type, name=...)`.

To screen the prompts a target receives, or the replies it sends, put a guardrail model in front of any of these targets: see [Guardrails](./guardrails.mdx).

## Need Another Integration?

If you need support for a different framework, please [open an issue](https://github.com/AISecurityLab/hackagent/issues) or contribute via a pull request!
